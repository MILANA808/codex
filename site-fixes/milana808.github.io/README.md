# MILANA808 GitHub Pages site

Готовый статический сайт для `MILANA808/milana808.github.io`.

## Что внутри

- Полностью автономный сайт без CDN и сборки.
- Красивая светлая тема по умолчанию и переключатель в космическую тёмную тему.
- Видимая анимированная Солнечная система с планетами и переключателем масштаба.
- AKSI Globe — центральный блок с идеей заботы, знаний, безопасности и связи людей.
- Полезные разделы для посетителей: быстрые действия, знания, добрые сообщения, планеты и офлайн-советы.
- Единый центр репозиториев: сайт сам подтягивает публичные проекты `MILANA808` и связывает их на одной странице.
- Доступность: семантическая разметка, клавиатурная навигация, `aria-live`, уважение к `prefers-reduced-motion`.

## Как опубликовать

Скопируйте файлы из этой папки в корень репозитория `milana808.github.io`:

```bash
cp index.html styles.css app.js /path/to/milana808.github.io/
cd /path/to/milana808.github.io
git add index.html styles.css app.js
git commit -m "Build AKSI Globe solar system site"
git push
```

GitHub Pages автоматически опубликует сайт из корня репозитория.

## Локальная проверка

```bash
python3 -m http.server 8080
```

Откройте `http://localhost:8080` и проверьте разделы, кнопки, планеты и переключатель масштаба.
